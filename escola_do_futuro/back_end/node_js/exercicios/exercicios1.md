**1.** O que é o Node.js?
É um ambiente de tempo de execução de codigo aberto.

**2.** O Node.js usa qual linguagem de programação?
javaScript

**3.** O Node.js roda no navegador ou fora dele?
não, ele não roda nativamente dentro do nagevador

**4.** Para que serve o Node.js?
para executar codigo JavaScript

**5.** Qual comando é usado para executar um arquivo Node.js no terminal?
NODE junto do nome do arquivo

**6.** O que é o **npm**?
é o gerador de pacotes padrão para Nod.js e o maior registro de software de codigo aberto do mundo.

**7.** O que significa a palavra **módulo** no Node.js?
é uma unidade de código encapsulada, geralmente um arquivo JavaScript ou uma pasta contendo multiplos arquivos

**8.** O Node.js é mais usado no **front-end** ou no **back-end**?
front-end

**9.** O que é o arquivo **package.json**?
é o coração de projetos Node.js e JavaScript, sendo o arquivo central de dependência.

**10.** O Node.js é gratuito ou pago?
totalmente gratuito
